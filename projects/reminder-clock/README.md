# 桌面倒计时提醒器

## 项目简介

一个偏桌面使用场景的倒计时提醒工具，适合专注计时、任务提醒和日常小节奏管理。

## 功能特点

- 支持新增多个倒计时任务
- 支持全部开始、全部暂停、全部重置
- 支持声音提醒、桌面通知、移动端震动
- 支持到点浮窗提醒
- 支持自动重复当前任务
- 支持锁定配置，避免误修改
- 使用 `localStorage` 保存本地配置

## 文件结构

```text
reminder-clock/
├─ index.html

```

## 使用方式

这是一个单文件网页工具。

1. 直接双击打开 `index.html`
2. 或在仓库根目录启动静态服务后访问 `projects/reminder-clock/index.html`

## 适合场景

- 学习番茄钟
- 固定工作节奏提醒
- 多任务轮换提醒
- 日常喝水、起身、休息等轻提醒
