# 图片无缝拼接工具

## 项目简介

一个本地浏览器图片拼接工具，可把多张图片按顺序拼成一张长图或横向拼图，适合做截图合并、素材排版和快速出图。

## 功能特点

- 支持选择文件、拖拽上传、剪贴板粘贴图片
- 支持纵向拼接和横向拼接
- 支持左对齐、居中、右对齐
- 支持设置图片间距、外边距、背景色
- 支持按最大尺寸、最小尺寸或指定尺寸统一缩放
- 支持生成后下载图片或复制图片

## 使用方式

这是一个单文件网页工具。

1. 直接双击打开 `index.html`
2. 或在仓库根目录启动静态服务后访问 `projects/image-stitcher/index.html`

## 适合场景

- 聊天截图拼长图
- 多张海报或素材快速合并
- 教程步骤图整理
- 简单拼版与结果导出
